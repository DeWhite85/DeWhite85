### Projects

**[Enterprise IAM Architecture](https://github.com/DeWhite85/nexus-financial-iam-architecture)**
A full identity architecture for a fictional 2,000-person financial services firm. Conditional Access, PIM, Identity Governance, B2B/B2C, and OAuth 2.0 / OIDC SSO across three applications, with 10 architecture decision records explaining the tradeoffs behind each choice.

**[Microsoft Sentinel Detection Engineering](https://github.com/DeWhite85/sentinel-detection-engineering)**
A 10-rule KQL detection library covering break glass sign-ins, PIM activation anomalies, brute force and Conditional Access tampering, each mapped to MITRE ATT&CK. Deployed programmatically through PowerShell and the Azure REST API, with Logic Apps playbooks for automated containment.

**[Application Threat Model](https://github.com/DeWhite85/application-threat-model)**
STRIDE and PASTA applied to a self-hosted financial application. Trust boundaries mapped, five vulnerabilities documented with CVSS scores, and two full attack chains modeled including AiTM session token replay and insider record manipulation.

**[CIS Azure Foundations Benchmark Automation](https://github.com/DeWhite85/cis-azure-benchmark-automation)**
Automated assessment across 100+ CIS controls using Azure Policy and PowerShell, producing an audit-ready report that ranks findings by risk and remediation order.

**[Purple Team Exercise](https://github.com/DeWhite85/purple-team-exercise)**
An ATT&CK technique executed in an isolated lab, detection validated in Sentinel, coverage gaps identified, and the whole thing written up for CISO-level review.
